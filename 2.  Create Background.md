
UI Canvas Backdrop (Recommended for Static Screens)

This method pins the image directly to the player's screen, stretching it automatically to match different aspect ratios.
1. Create the UI Element: Right-click in the Hierarchy, select UI, and choose Image (or Panel). This will automatically generate a Canvas and an EventSystem.
2. Assign the Texture: Select the newly created Image child object, and drag your background sprite into the Source Image slot in the Inspector.
3. Stretch to Fit: Click the RectTransform Anchor Preset box (the square target icon). Hold Alt (Windows) or Option (Mac) and click the bottom-right stretch-stretch block. This forces the image to perfectly cover the screen.
4. Fix Foreground Occlusion: If your UI background covers your player and gameplay, change the Canvas Render Mode from Screen Space - Overlay to Screen Space - Camera. Drag your Main Camera into the Render Camera slot.
