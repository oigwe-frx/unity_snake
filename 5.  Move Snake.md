
How to use this script in Unity:

1. Create the Script: Right-click in your Project window → Create → C# Script, and name it SnakeMovement.
2. Paste the Code: Open the script and replace its contents with the code block above.
3. Attach to Snake: Drag and drop this script onto your Snake head game object in the Hierarchy.
4. Press Play: The snake will immediately and continuously move upward. You can adjust the Speed parameter directly in the Inspector window while the game is running to find the perfect pace.

```
using UnityEngine;

public class SnakeMovement : MonoBehaviour
{
    [Header("Movement Settings")]
    [Tooltip("Speed of the snake's movement")]
    public float speed = 5f;

    // The direction vector initialized to always point upwards
    private Vector2 moveDirection = Vector2.up;

    void Update()
    {
        // Moves the snake up by 'speed' units per second along the Y-axis
        transform.Translate(moveDirection * speed * Time.deltaTime);
    }
}
```
